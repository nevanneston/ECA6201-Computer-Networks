This project presents a comprehensive enterprise security architecture designed using Cisco Packet Tracer.
The network integrates firewall-based access control to protect internal resources.
Extended ACLs are configured to allow authorized traffic and restrict unauthorized services.
The architecture includes separate enterprise and branch networks for better security.
A VPN connection is represented between the main and branch routers.
IDS/IPS concepts are incorporated to identify and prevent suspicious network activities.
A web server is included as a protected enterprise resource.
Connectivity tests are performed to verify authorized communication between devices.
Restricted traffic scenarios are tested to evaluate the effectiveness of the firewall rules.
Overall, the simulation demonstrates how firewall, IDS/IPS, and VPN mechanisms improve enterprise network security.
